# corpora-agent

This Rust crate reserves a place for a future agent runtime. It has **no
public agent methods or parameters yet**.

The working [Text-Fabric expert bundle](../../agent/text-fabric-expert/README.md)
contains instructions and host configuration. The
[TF AI resolver](../../packages/tf-ai-resolver/README.md) can ask that expert
for a proposal about one selected piece of TF text. Its README shows the
commands and review step.
