# corpora-convert

Conversion runners for the Corpora apps suite.

Part of [corpora-core](https://github.com/exegia/corpora-core).

`corpora_convert::epub::validate_epub` is the reusable local EPUB validation
and reading projection API. `corpora-epub-check` exposes its member-scoped shared
diagnostics as JSON. See `packages/epub-to-tf/README.md` for the bounded input
policy and Text-Fabric export command.
